# نورونا: دعوات أفراح رقمية

موقع واحد على **Cloudflare Workers**: نفس الـ Worker بيخدم الواجهة (اللاندينج والمصمم) وبيرد على الـ API.
الداتابيز **D1**، وصور العرسان على **R2**. كله شغال على الخطة المجانية.

## إزاي المنتج بيشتغل
1. العرسان بيصمّموا الدعوة ببلاش على الصفحة الرئيسية، ويدوسوا «اطلبوا دعوتكم».
2. الطلب بيتسجّل (رقم زي `Z-4821`) والدعوات بتتعمل «بتتجهّز»، والعرسان بياخدوا:
   - لينك معاينة يبعتوه معاكم على الواتساب.
   - **لينك لوحة المعازيم** الخاص بيهم (بيظهر مرة واحدة بس، ومتسجّل على جهازهم كمان).
3. بيحوّلوا الفلوس (إنستاباي / فودافون كاش) ويبعتوا الإيصال واتساب.
4. انتو بتفتحوا `/admin` وتدوسوا **«تم الدفع»**: الدعوات بتشتغل لحد آخر ميعاد فيها + ٣٠ يوم، ولوحة الأدمن بتجهّزلكم رسالة اللينكات للعرسان.
5. الضيوف بيفتحوا `/ahmd-sara`، يعيشوا الافتتاحية، ويأكدوا حضورهم. العرسان بيشوفوا كل حاجة في لوحتهم ويعدّلوا الدعوة في أي وقت.

## محتوى المشروع
| المكان | فيه إيه |
|---|---|
| `public/` | الواجهة كلها (static): `index.html`، `assets/`، `img/` (صور القوالب + `img/og/` صور معاينة الواتساب) |
| `public/assets/invite.*` | محرك الدعوة (القوالب والافتتاحيات). نفس المحرك في الصفحة الرئيسية والمصمم وصفحة الضيف |
| `public/assets/site.*` | الصفحة الرئيسية والمصمم والطلب |
| `public/assets/guest.*` `dash.*` `admin.*` | صفحة الضيف، لوحة العرسان، لوحة الأدمن |
| `src/` | الـ Worker (TypeScript + Hono) |
| `src/pricing.ts` | **الأسعار** (المكان الوحيد). الواجهة بتقراها من `/api/config` |
| `migrations/` | جداول D1 |
| `scripts/seed.mjs` | دعوة تجريبية شغالة على `/ahmd-sara` فيها ردود |
| `test/` | التستات (vitest) |
| `wrangler.jsonc` | الإعدادات: D1، R2، أرقام الدفع والواتساب والدومين |

### الأسعار
دعوة ٢٩٩، دعوتين ٤٤٩ (التانية بنص السعر)، ٣ دعوات ٥٩٨ (التالتة ببلاش). إضافة الصور +١٩٩ **لكل دعوة**.
دعوة «حنة وفرح» بتتحسب دعوة واحدة. التعديل في `src/pricing.ts` بس.

### أرقام الدفع والواتساب والدومين
في `wrangler.jsonc` تحت `vars`:
- `INSTAPAY`: حساب إنستاباي.
- `VFCASH`: رقم فودافون كاش.
- `WHATSAPP`: رقم الواتساب بالكود الدولي من غير +، مثلًا `201012345678`.
- `PUBLIC_DOMAIN`: الدومين، مثلًا `nawarona.app`.

## تشغيله على جهازك
محتاجين Node.js 18 أو أحدث.

```bash
npm install
```

اعملوا ملف `.dev.vars` في فولدر المشروع (ممنوع يترفع على git) فيه أسرار التجربة:

```
ADMIN_PASSWORD=أي-باسورد-للتجربة
SESSION_SECRET=أي-نص-عشوائي-طويل
KEY_PEPPER=أي-نص-عشوائي-طويل-تاني
```

وبعدين:

```bash
npm run db:migrate:local
```

```bash
node scripts/seed.mjs
```

```bash
npm run dev
```

افتحوا `http://localhost:8787`. الـ seed بيطبع لينك صفحة الضيف ولينك لوحة العرسان. والأدمن على `http://localhost:8787/admin` بالباسورد اللي في `.dev.vars`.

### التستات
```bash
npm test
```

## الرفع على Cloudflare (أول مرة)
كل الأوامر من فولدر المشروع، وبالترتيب ده:

**١. سجّلوا دخول على حساب Cloudflare** (هيفتح المتصفح):
```bash
npx wrangler login
```

**٢. اعملوا الداتابيز:**
```bash
npx wrangler d1 create zaffa
```
هيطلعلكم `database_id`. انسخوه وحطوه في `wrangler.jsonc` مكان `00000000-0000-0000-0000-000000000000`.

**٣. اعملوا مكان الصور والأغاني:**
```bash
npx wrangler r2 bucket create zaffa-media
```

**٤. حطوا الأسرار** (كل أمر هيسألكم على القيمة). استخدموا قيم جديدة طويلة وعشوائية، مش اللي في `.dev.vars`:
```bash
npx wrangler secret put ADMIN_PASSWORD
```
```bash
npx wrangler secret put SESSION_SECRET
```
```bash
npx wrangler secret put KEY_PEPPER
```
- `ADMIN_PASSWORD`: باسورد لوحة الأدمن.
- `SESSION_SECRET`: بيوقّع جلسة الأدمن ولينكات المعاينة. لو اتغيّر، لينكات المعاينة القديمة بتبطل.
- `KEY_PEPPER`: بيعمل hash لمفاتيح لوحات العرسان. **ما تغيّروهوش أبدًا بعد ما الناس تطلب**، وإلا كل لينكات لوحات العرسان هتبطل.

لنص عشوائي كويس:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

**٥. اعملوا الجداول في الداتابيز الحقيقية:**
```bash
npx wrangler d1 migrations apply zaffa --remote
```

**٦. ارفعوا الموقع:**
```bash
npx wrangler deploy
```
هيطلعلكم لينك `…workers.dev` تقدروا تجرّبوا عليه على طول.

**٧. اربطوا الدومين:** من لوحة Cloudflare: **Workers & Pages ← nawarona ← Settings ← Domains & Routes ← Add ← Custom domain**، واكتبوا الدومين (لازم يكون على نفس حساب Cloudflare). أو حطوا في `wrangler.jsonc`:
```jsonc
"routes": [{ "pattern": "nawarona.app", "custom_domain": true }]
```
وارفعوا تاني بـ `npx wrangler deploy`.

### تحديثات بعد كده
- تعديل في الكود أو الواجهة: `npx wrangler deploy`.
- migration جديدة في `migrations/`: `npx wrangler d1 migrations apply zaffa --remote` قبل الـ deploy.
- دعوة تجريبية على الموقع الحقيقي (اختياري): `KEY_PEPPER=نفس-القيمة-اللي-في-secrets node scripts/seed.mjs --remote`

## لوحة الأدمن (`/admin`)
- الطلبات بالأحدث، وفلتر بالحالة، وبحث برقم الطلب (`4821` أو `Z-4821`) أو الموبايل بأي شكل.
- **«تم الدفع»**: الدعوات بتشتغل، وبتظهر رسالة جاهزة بلينكات الدعوة تبعتوها للعرسان واتساب.
- إلغاء الطلب (الدعوات بتتقفل)، ملاحظة داخلية، ومدّ صلاحية الدعوة ٧ أو ٣٠ يوم.
- الدخول بالباسورد بس، والجلسة ١٢ ساعة. بعد ١٠ محاولات غلط بيستنى ربع ساعة.

## لوحة العرسان (`/d/<slug>?k=…`)
الأعداد من الطرفين، كل الردود (بحث وفلتر وتنزيل إكسل)، قفل باب الردود، تعديل المواعيد والبرنامج والملاحظات وكلام الدعوة.
القالب والأسامي بيتغيّروا قبل التفعيل بس. ولو الطلب فيه إضافة الصور واتدفع: صورة غلاف و٦ صور (بتتصغّر في المتصفح). مفيش موسيقى ولا أغاني في الدعوات خالص.

**لو العرسان ضيّعوا لينك اللوحة:** المفتاح مش متخزّن عندنا (بس الـ hash بتاعه)، فمش هتقدروا تبعتوه تاني. اللينك متسجّل على الجهاز اللي طلبوا منه (في «طلباتكم اللي فاتت» في شاشة الطلب).

## حدود الخطة المجانية وإزاي المشروع ماشي جواها
| الحد | المشروع |
|---|---|
| ١٠ms CPU للطلب | تشفير Web Crypto بس، ومفيش معالجة صور على السيرفر (الصور بتتصغّر في المتصفح) |
| ١٠٠ ألف طلب Worker في اليوم | الملفات الـ static مش بتتحسب. اللي بيتحسب: فتح الدعوة، الـ API، وصور العرسان (لحد ٧ طلبات لضيف بيفتح دعوة فيها صور) |
| D1: ٥ مليون قراية و١٠٠ ألف كتابة في اليوم | كل البحث على أعمدة عليها index. فتح الدعوة = كتابة واحدة (عدد المشاهدات) |
| R2: ١٠ جيجا | الدعوة اللي فيها صور حوالي ٢–٤ ميجا |

### حاجات تتعمل بعدين لو المشروع كبر
- الملفات القديمة على R2 مش بتتمسح لوحدها بعد انتهاء الدعوة.
- لو طلبات الصور قربت من الحد، اربطوا R2 بدومين عام عشان الصور تتخدم من غير الـ Worker.

### نسخ الصور الصغيرة (السرعة على الموبايل)
الكروت والموبايل اللي في أول الصفحة بيستخدموا نسخ صغيرة في `public/img/sm/`، والملف `public/assets/hero-sm.css` متولّد منها. لو غيّرتوا أو زوّدتوا صورة قالب، شغّلوا:

```bash
python scripts/make-small-images.py
```

### معاينة الصفحة الرئيسية لما تتشارك
تاجات `og:` في أول `public/index.html` مكتوب فيها دومين الـ workers.dev. لو الدومين مختلف غيّروه هناك.
